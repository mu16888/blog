> 📚 本文是《公文写作系统》系列之一。


效率不一定靠买贵软件。下面 5 个免费工具，解决的是打工人每天都会撞上的小痛点，装一个就回本。

## 1. Everything —— 本地文件秒搜

Windows 自带搜索慢得让人想砸键盘。Everything 索引全盘后，输文件名**实时出结果**，找文档、找历史稿子一秒定位。免费、体积小、常驻后台零负担。

## 2. Snipaste —— 截图 + 贴图标注

普通截图只能存图。Snipaste 能把截图**贴在屏幕最上层**当参照，改稿时对照前后版本极方便；标注、箭头、文字也顺手。免费的"贴图"能力是它独门。

## 3. 在线 PDF 工具（ilovepdf / smallpdf）

合并、拆分、压缩、转 Word，这些低频但刚需的 PDF 操作，在线工具免费额度够日常用。敏感文件注意脱敏后再上传。

## 4. VS Code / Typora —— 写长文档更顺

需要写结构复杂的文档（方案、报告），用 Markdown 编辑器（Typora 付费但轻量；VS Code 免费）先搭骨架再导出，比在 Word 里来回调格式清爽得多。

## 5. Quicker / AutoHotkey —— 把重复操作录成一键

每天重复点一样的菜单？Quicker（可视化）或 AutoHotkey（脚本）能把一串操作绑到一个快捷键。第一次配置花十分钟，之后每次省三十秒，积少成多。

## 一个小提醒

工具是杠杆，**先想清楚要自动化哪件事，再选工具**，别反过来为用工具而用工具。把上面 5 个里和你痛点重合的装上一两个，日常就能明显轻松些。
