红头文件最怕"差两毫米"。下面这份对照表，把 GB/T 9704-2012 里最常卡的版式要点列出来，写材料或排版时对着查一遍，能避掉大部分格式返工。

> 说明：以下为通用规范要点，具体以**本单位规定和最新国标**为准。

| 项目 | 规范要点 |
|---|---|
| 发文机关标志（红头） | 红色，推荐使用小标宋体；一般上边缘距版心上边缘约 35mm |
| 发文字号 | 发文机关标志下空二行；下行文居中，上行文左空一字；年份用六角括号〔〕 |
| 红色分隔线 | 在发文字号下 4mm 处，与版心等宽，红色 |
| 标题 | 分隔线下空二行，2 号小标宋体，居中 |
| 主送机关 | 标题下空一行，左顶格，回行顶格 |
| 正文 | 3 号仿宋体；一般每页 22 行、每行 28 字 |
| 层次序数 | 一、（一）1.（1） 四级，字体逐级变化 |
| 附件说明 | 正文下空一行左空二字，"附件：1.××" |
| 发文机关署名 | 一般右空二字 |
| 成文日期 | 阿拉伯数字，"2026年10月19日"，右空四字 |
| 印章 | "骑年盖月"，压署名与日期 |
| 页码 | 4 号半角宋体阿拉伯数字，一般作"- 1 -"形式 |

## 怎么用这张表

1. **排版前**：先把红头、发文字号、分隔线位置定好，这是"骨架"；
2. **写正文时**：正文用仿宋、固定行字数，别随手改字体；
3. **出稿后**：拿这张表逐项过一遍，重点查发文字号括号、层次序数、页码、落款位置。

手工调这些容易漏，所以很多人把版式做成模板或脚本，出稿一键套用——省的就是返工的那半天。
