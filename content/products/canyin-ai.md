# 餐饮 AI 助理 · 说句话，把店里的账算清楚

> 不是又一份"餐饮资料包"。资料包你打开就关上了，因为不会用。
> 这套东西是**能装进 AI 的技能**：你说一句「红烧肉卖 38，五花肉 26 一斤」，它直接把成本和毛利算给你。
>
> 底子是三十年厨房经验 + 46 张表 + 1202 份知识库。装不上 AI 也能当文件用——蓝底填数，黄底别动。

## 它解决的是"算不清"

开店最怕的不是忙，是忙完不知道赚没赚。

- 卖 38 的一道菜，到底赚多少，凭感觉；
- 菜单六十道，一半在拖后腿，不知道砍哪个；
- 师傅一走，招牌菜就变味；
- 月底流水有数，利润没数。

这些事靠脑子记不住，靠 Excel 又不会做。所以我们把它交给了 AI。

## 两个版本，按需选

| | 餐饮老板版 | 食堂老板版 |
|---|---|---|
| 卖给谁 | 单店老板、店长、厨师长 | 食堂承包方、后勤负责人 |
| 核心能力 | 成本卡、选址、菜单、诊断、例会、运营 | 排菜、采购、记账、投标、食安、定岗 |
| 源文件 | 13 模块 163 份（46 张 Excel / 112 份 Word） | 26 份（14 张表） |
| 知识库 | 1202 份（756 份菜谱） | 65 份 + 大锅菜菜品库 |
| 原价 | 999 | 599 |
| **首发价** | **399** | **299** |

## 它怎么干活

| 你说 | 它给 |
|---|---|
| 红烧肉卖 38，五花肉 26 一斤 | 成本卡 + 毛利率 65% |
| 这店能不能接，房租 8000 | 保本线 + 能不能接的结论 |
| 菜单 60 道，砍到 40 道 | 砍菜清单 + 定价建议 |
| 这个月流水 8 万，食材 2.9 万 | 经营体检 + 三条改进 |
| 600 人、餐标 12，排一周 | 7 天菜单 + 采购量 + 人均成本 |

固定节奏：**结论先行 → 三条依据 → 一个动作**。不给一堆"建议综合考虑"。

## 怎么装

三步，opencode、workbuddy、DSH、Claude Code 都能用：

1. 把文件夹放进 Agent 的技能目录（不知道在哪，直接问它「你的 skills 目录在哪」）
2. 说一句：「读取《餐饮老板AI助理V2.0.2》文件夹，读 SKILL.md，按规则工作」
3. 自测：「红烧肉卖 38，五花肉 26 一斤，算成本卡」——答得出毛利率，就装好了

装不上也没关系：包里带全部源文件，打开就能填。

## 买之前
